# IDK what to name this
Its just a simple wolfenstein style ASCII raycaster made in c. It is a project i made when i was 13 when i was trying to experiment with graphics. The original source is in the old.cpp, please dont judge 13 yr old me's bad code. I cleaned up the project and shifted it to c. It is written in c with ncurses to do the rendering and input.

## build and run
build using the build.sh script or directly using `gcc main.c -o out -lcurses -lm`

then run directly though terminal with `./out`

## Controls
Esc to quit

Up arrow to move front

Down arrow to move back

Left arrow to look left

Right arrow to look right
